# Hands-on sessions

Guided exercises, starter configurations, scripts, small datasets, and expected outputs for the computational sessions.

| Session | Instructor | Materials |
|---------|------------|-----------|
| Day 1 — Fundamentals of Molecular Simulations (GROMACS) | Dr Valentina Erastova | [00_MD_Intro_GROMACS](00_MD_Intro_GROMACS/) |

Each exercise should include:

- learning objectives and estimated duration;
- prerequisites and tested software versions;
- setup instructions;
- a clearly numbered workflow;
- expected outputs or validation checks;
- cleanup instructions where relevant; and
- licence, citation, and contributor information.

Put visuals specific to the hands-on material in `Figures/`. Shared introductory visuals belong in the top-level `Assets/` folder.

Avoid committing credentials, participant data, proprietary input files, or very large simulation outputs.
