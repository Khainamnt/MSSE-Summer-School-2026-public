# Contributing materials

Thank you for contributing to MSSE 2026.

## Presenters and instructors

1. Place the file in the appropriate `01_Research-Led-Presentations/day-*` or `02_Hands-On-Sessions/` folder. Pre-course setup material belongs in `00_Pre-Instructions/`.
2. Use a lowercase, descriptive filename without spaces.
3. Add research-led material to `01_Research-Led-Presentations/README.md` and to the relevant day's `README.md`.
4. Put section-specific visuals in that section's `Figures/` folder. Use the top-level `Assets/` folder only for shared introductory or repository-level visuals.
5. Include a licence or explicit reuse statement for your contribution.
6. Open a pull request, or ask the organising team to upload the file for you.

Before submitting, please remove private notes, participant data, unpublished credentials, API keys, and material you do not have permission to redistribute.

## Large files

GitHub rejects individual files larger than 100 MB. For large trajectories, datasets, or videos, deposit the material in an appropriate research-data repository and add a persistent link and citation here instead.

## Pull requests

In the pull-request description, identify the contributor, session, file(s), and reuse permission. A submission is not considered approved for public release until the contributor or an authorised organiser confirms it.

## Corrections

For factual corrections or broken links, open an issue with the affected path and the proposed correction. For urgent privacy or rights concerns, contact the organisers directly via the addresses in the main README.
